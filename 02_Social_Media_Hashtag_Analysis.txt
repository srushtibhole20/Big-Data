//USE CASE 2: Social Media Hashtag Analysis

 1. Problem Statement

A social-media platform stores user posts in HDFS. Each post contains information such as post ID, username, caption and hashtags.
The data engineering team wants to determine how many posts contain each hashtag.
The MapReduce application should:

1. Read social-media post data from HDFS.
2. Extract hashtags.
3. Generate (hashtag, 1) using a Python Mapper.
4. Use a Combiner for local aggregation.
5. Use Hadoop's Partitioner to distribute hashtags among Reducers.
6. Shuffle and group identical hashtags.
7. Calculate the final hashtag frequency.
8. Store the result in HDFS.


# 2. Sample Input
social_posts.txt

//
P1001 rahul #python #hadoop #bigdata
P1002 priya #python #spark
P1003 amit #hadoop #spark #bigdata
P1004 neha #python #bigdata


3. Expected Output
#bigdata    3
#hadoop     2
#python     3
#spark      2

7. Combiner Stage

Suppose one Mapper receives several records.

Instead of sending:
#python    1
#python    1
#python    1
#bigdata   1
#bigdata   1


the Combiner can produce:
#python    3
#bigdata   2

This reduces intermediate network traffic.


8. Partitioner Stage

Hadoop's default Partitioner determines which Reducer receives each hashtag.

//Conceptually:

#python  → Reducer 0
#hadoop  → Reducer 1
#bigdata → Reducer 0
#spark   → Reducer 1

//Again:

Same key → Same Reducer

This is essential for obtaining the correct final count.


9. Shuffle and Sort

//Hadoop groups the same hashtags:

#bigdata → [1,1,1]
#spark   → [1,1]

# Big Data Technologies – Lab Use Cases

## About This Repository
This repository contains Big Data technology use cases, practical examples, commands, and expected outputs for lab practice and learning.

## Use Cases

### 1. Web Server HTTP Status Code Analysis
- **Technology:** Hadoop MapReduce
- **Objective:** Analyze web server logs and count HTTP status codes.
- **Concepts:** Mapper, Reducer, Combiner, Partitioner, and HDFS.

### 2. Social Media Hashtag Analysis
- **Technology:** Hadoop MapReduce with Python Streaming
- **Objective:** Count the frequency of hashtags in social media posts.
- **Concepts:** Python Mapper, Combiner, Reducer, HDFS, and Hadoop Streaming.

### 3. MapReduce Comparison and Lab Demonstration
- **Technology:** Hadoop MapReduce
- **Objective:** Understand MapReduce concepts and their practical workflow.

## Technologies Used
- Apache Hadoop
- HDFS (Hadoop Distributed File System)
- MapReduce
- Python
- Hadoop Streaming

## Learning Objectives
- Understand distributed data processing.
- Learn how Hadoop MapReduce works.
- Practice processing data stored in HDFS.
- Execute MapReduce jobs and analyze their output.
